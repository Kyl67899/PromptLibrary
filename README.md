# PromptLibrary

PromptLibrary is a community-driven prompt collection for building frontend features using AI-assisted prompts. It helps developers explore UI patterns, customize component behavior, and build new layouts faster with reusable prompt templates.

## Features

- Prompt library for frontend UI patterns and component designs
- Modern Next.js application structure with `app/`, `components/`, and `lib/`
- Admin API endpoints for campaigns, prompts, and newsletter workflows
- Ready for extension and community contributions

Follow my blog post on [dev.to](https://dev.to/kyl67899/bikeapi-1i7o) and [Hashnode.com](https://hashnode.com/@csdevfe)

## Getting Started

### Requirements

- Node.js 22+ or later
- npm or compatible package manager

### Install

```bash
npm install
```

### Run the app locally

```bash
npm run dev
```

Open `http://localhost:3000` in your browser to view the app. Run locally in ports in the terminal do not publish on the web platforms.

## Project Structure

- `app/` - application routes, pages, and API endpoints
- `components/` - reusable UI components and shared interface elements
- `lib/` - utilities, stores, and data helpers
- `public/` - static assets and preview files
- `styles/` - global and shared styles

## 🤝 Contributing

We welcome contributions! Here's how you can help:

1. **Fork the repository**
2. **Create a feature branch** (`git checkout -b feature/add-prompts`)
3. **Add or update prompts data** in `lib/prompts-data.ts`
4. **Commit your changes** (`git commit -m 'Add new prompt'`)
5. **Push to the branch** (`git push origin feature/add-prompts`)
6. **Open a Pull Request**

### Contribution Guidelines

- Ensure all prompts libraries data comes from official sources or own ideas
- Maintain consistent data structure and formatting
- Update both `db.json` and `data/bike.json` simultaneously
- Add meaningful commit messages
- Add meaningful pull requests
